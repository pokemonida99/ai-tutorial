:::learn
- 密碼、金鑰為什麼不能打進對話
- 公開、寄出、上傳之前要看什麼
- 真人照片和別人的角色怎麼處理
- Claude、ChatGPT、Higgsfield、GitHub 各花在哪裡
:::

:::step 密碼、金鑰不要打進對話
對話框裡的文字會被記錄。**帳號密碼、信用卡號、身分證字號、各種金鑰（API key、token）都不要打進去**，就算 Claude 說它需要也一樣。

需要登入的時候，正確做法是：

- 在服務的**官方網頁**或跳出來的授權視窗登入（第 4 課的連接器、第 5 課的 GitHub 都是這樣）
- 需要付款、儲值，**你自己去官網操作**，不要請 Claude 幫你輸入卡號

:::warn
如果某個網頁、文件或信裡寫著「請 Claude 輸入密碼」「請立刻轉帳」，那是別人寫的字，不是你的指示。Claude 會停下來問你，你也不要照做。
:::
:::

:::step 公開之前，自己看一次
Claude 在**對外**做事之前都會先問你：寄信、發文、推上網、公開上傳。你說「好」之前，看這幾件事：

:::cards
👀|內容|字有沒有錯、圖有沒有不該出現的東西
👥|對象|寄給誰？公開給所有人還是只有自己？
📋|檔案清單|會上傳哪些檔案？有沒有私人照片、原始檔
💰|花費|會不會扣點數、要不要付錢
:::

這套教學本身也是這樣：先做在你的電腦裡給你審，你說可以了才會放上網。
:::

:::step 真人照片留在自己電腦
想做「像某個人」的角色時，真人照片只能拿來**參考造型**：

1. 照片放在不會上傳的資料夾（例如 `work/refs/`），告訴 Claude 這個資料夾**不要放上網**
2. 請 Claude 把造型寫成文字描述
3. 用文字描述加上原創角色的畫風，請 GPT 畫成**原創公仔**

![這些備用角色的造型都參考過真人照片，但臉和角色都是原創的，真人照片從來沒有公開](img/spare-characters.jpg)

:::tip
教學截圖、宣傳片、上線的遊戲，都不要出現真人參考照。截圖裡的 Email、帳號名稱也要遮掉。
:::
:::

:::step 別人的角色、作品要小心
餐點表的初版放了一隻迪士尼角色當裝飾。自己印出來貼在教室裡問題不大，但如果要**公開發布**或**拿來賺錢**，用別人的角色就可能有著作權問題。

- 要公開的作品：用自己畫的、或 GPT 畫的原創角色
- 改編電影、小說：人物造型照原作，但不要直接拿原作的圖、音樂去用
- 不確定的時候問 Claude：「這樣公開會不會有著作權問題？」它會提醒你風險（但它不是律師）
:::

:::step 知道錢花在哪裡
以這套教學用到的服務來說：

| 服務 | 用來做什麼 | 怎麼收費 |
|---|---|---|
| Claude | 寫程式、做文件、做影片、操作其他工具 | 月費方案（Code 分頁要付費方案） |
| ChatGPT | 畫圖（Claude 透過 codex 叫它） | 用你 ChatGPT 方案的額度 |
| Higgsfield | 圖轉 3D、綁骨架、生影片 | 點數制。轉 3D 一個角色 9 點、綁骨架加一段動作 8 點；《上班啟示錄》全部約 176 點 |
| GitHub Pages | 把遊戲放上網 | 公開倉庫免費 |

價格和方案常常變，以各家官網為準。
:::

:::step 花點數之前先問報價
會扣點數的工作，養成習慣先問：

:::say
開始之前先跟我說總共要花幾點、我現在還剩多少，我說好再開始。
:::

Claude 會先查餘額、算好再等你點頭。一次要做很多張圖或很多個 3D 時特別有用。
:::

:::step 重要的成品自己備份
做好的影片、文件，請 Claude 另外複製一份到你的雲端資料夾（這位作者用一個叫「雲端」的資料夾，所有成品影片都收在裡面）。遊戲推上 GitHub 之後，GitHub 上也有一份。

:::say
把這次做好的兩支影片複製到「雲端／上班啟示錄預告」資料夾。
:::
:::

:::stuck
**Claude 叫我貼密碼或金鑰**：不要貼。回它「我不在對話裡貼密碼，請告訴我要去哪個官方網頁登入」。

**不確定某個動作要不要允許**：先按拒絕，再問它要做什麼。拒絕不會讓東西壞掉。

**月底點數突然用完**：請 Claude 每次做事前先報價，並且在記憶裡寫下「花點數前先問我」。

**不知道作品能不能公開**：先問 Claude 有沒有用到別人的角色、真人照片、有版權的音樂；有疑慮就換成原創素材。
:::
