## 檔案
- `md/`：文字原稿（要改字改這裡）。`index.md` 是目錄頁，`01`～`06` 是六課。
- `tools/build.py`：把 md 轉成網頁，改完 md 執行 `python3 tools/build.py`。特殊區塊的寫法寫在 build.py 開頭。
- `*.html`＋`style.css`：產生出來的網頁（不要直接改 html）。
- `img/`：教學用圖（遊戲截圖、GPT 角色圖、官網下載頁截圖）。
- `審稿截圖/`：手機寬度整頁截圖，給審稿用，不上線。

## 本機預覽
launch.json 的 `ai-tutorial`（port 4470），或 `python3 -m http.server 4470 --directory ai-tutorial`。

## 規則
- 不放真人參考照（在 `office-apocalypse/work/refs/`，私人）。
- 截圖裡的 Email、帳號名稱要遮。餐點表右上的迪士尼角色已模糊。
- Claude 桌面版、連接器、授權畫面這 8 張（img/mock-*.png）是程式畫的示意圖，原稿在 `tools/mocks.html`，`node tools/mocks.cjs` 重新產生。以後有真的截圖可以換掉。
- 每課最後的「影片大綱」之後要拆成一課一支教學影片。
